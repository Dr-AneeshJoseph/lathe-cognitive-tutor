# Security & Ethics Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

L.A.T.H.E. is a cognitive modeling system. We define a "Vulnerability" as:
1.  **Technical Exploit:** Code injection, prompt injection, or crash loops.
2.  **Pedagogical Harm:** The system reinforcing a bias instead of correcting it, or causing excessive psychological distress via the "Paradox" or "Mirror" agents.

### How to Report
If you discover a flaw where the tutor becomes manipulative or factually hallucinated:

1.  **DO NOT** open a public issue.
2.  Email the maintainer directly.
3.  Include the transcript of the session where the agent failed.

We take the psychological safety of students seriously and will patch behavior loops within 48 hours.
